# Código de conducta

Esperamos una colaboración respetuosa, clara y profesional.

## Comportamientos esperados

- tratar a las demás personas con respeto;
- aceptar críticas técnicas constructivas;
- explicar desacuerdos sin ataques personales;
- proteger los datos y la privacidad de otras personas;
- mantener las discusiones centradas en el proyecto.

## Comportamientos no aceptables

- acoso, insultos o amenazas;
- discriminación o ataques personales;
- publicación de información privada;
- spam, sabotaje o cambios deliberadamente destructivos;
- inclusión de código malicioso, credenciales o datos reales.

El mantenedor puede editar, cerrar o rechazar contribuciones que no respeten estas reglas.
